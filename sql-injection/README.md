# SQL Injection

This folder contains my notes and writeups from the **SQL Injection** labs on [PortSwigger Web Security Academy](https://portswigger.net/web-security/sql-injection).

I'm using these labs to build a practical understanding of SQL injection — not just memorizing payloads, but understanding how SQL queries are constructed, how different types of SQL injection work, how to exploit them, and how they can be prevented.

## Topics Covered

The labs cover different SQL injection techniques, including:

- Basic SQL injection
- Authentication bypass
- Database enumeration
- UNION-based SQL injection
- Data extraction
- Blind SQL injection
- Conditional responses and errors
- Error-based SQL injection
- Time-based SQL injection
- out-of-band SQLi
- SQli with filter bypass via XML encoding

## About the Writeups

Each writeup keeps the exploitation process short and practical:

**Vulnerability → Objective → Exploitation → Impact → Remediation → Key Takeaway**

The goal is to make each writeup easy to follow for someone learning SQL injection while still documenting the technical details that matter during a real security assessment.

I'll continue updating this folder as I work through more SQL injection labs.
